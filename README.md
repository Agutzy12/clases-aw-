# Aplicaciones Web 1 — Clases y actividades

Repositorio con las actividades prácticas y los ejercicios de clase de la materia Aplicaciones Web 1.

## Actividades

Cada actividad tiene su propia carpeta con el código y el PDF con la consigna y la resolución.

| Actividad | Tema | Carpeta |
| --- | --- | --- |
| 5 | Sitio de 2 páginas en HTML básico para un cliente (nutricionista) | [actividad-05](actividades/actividad-05) |
| 9 | JavaScript: consola, operaciones, variables y constantes | [actividad-09](actividades/actividad-09) |
| 10 | JavaScript: condicionales y bucles `for` | [actividad-10](actividades/actividad-10) |
| 11 | JavaScript: funciones de declaración, flecha y callback | [actividad-11](actividades/actividad-11) |
| 12 | JavaScript: arreglos y objetos | [actividad-12](actividades/actividad-12) |

Para las actividades de JavaScript hay que abrir el `index.html` en el navegador y mirar los resultados en la consola (F12).

## Clases

- [Clase 15/04 — Servidor HTTP con Node](clases/clase-15-04-servidor-http): servidor con el módulo `http` que responde rutas GET y POST y guarda en un archivo los datos que trae de una API. Se ejecuta con `npm run dev`.
